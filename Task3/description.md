Безопасность:

Шифрование данных:
- Все коммуникации должны использовать TLS 1.3.
- Данные биометрии и номеров автомобилей шифруются на уровне базы (AES-256).

Контроль доступа:
- JWT-токены для аутентификации запросов.

Согласие на обработку данных:
- Реализовать механизм получения явного согласия пользователей на сбор биометрических данных ФЗ-152 в мобильном приложении.

Взаимодействие с системой партнера:
- API-ключи для аутентификации сервер-серверных запросов.


Вся инфраструктура Партнера должна соответствовать законам РФ в области информационной безопасности, хранению и обработки персональных данных.
